# Personal Assistant
A lightweight local Python assistant for Windows 11.

## Features
- Startup greeting with voice
- Activity tracking
- Website usage tracking
- Daily summaries
- App limiting
- Duplicate file detection
- System maintenance

## Technologies
- Python
- Win32 APIs
- psutil
- pywin32
- UI Automation

## Future roadmap
- Browser URL tracking
- AI summaries
- Weekly reports
- Productivity scoring
